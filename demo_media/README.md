# CivicOS 4K Demo Media

These high-resolution assets are included for hackathon presentation use. They are not loaded by the live website, so they do not slow down the application.

- `CivicOS_Intelligence_4K_Backdrop.png` — background for Civic Intelligence / prediction slides or demo screens.
- `CivicOS_Disaster_Operations_4K_Backdrop.png` — background for emergency-capacity / Disaster Operations explanations.
- `CivicOS_Public_Value_Optimizer_4K_Backdrop.png` — background for resource-allocation / public-value optimization explanations.

They are derived from the project’s own CivicOS visual texture and are included as real presentation assets rather than padding files.
