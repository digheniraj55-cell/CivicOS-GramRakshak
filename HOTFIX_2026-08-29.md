# CivicOS Hotfix — 29 Aug 2026

## Fixed: worker after-evidence upload crash
The worker completion form previously imported Pillow inside `save_file()`. On some Python 3.14 installations the Pillow import can fail; the old exception handler then referenced `UnidentifiedImageError` before that name existed, producing:

`UnboundLocalError: cannot access local variable 'UnidentifiedImageError' where it is not associated with a value`

The upload validator now uses PNG/JPEG/WEBP file signatures and does not require Pillow. Worker completion photo upload therefore continues to work even if Pillow is unavailable or incompatible.

## Improved: email and Google setup
Command Center → Settings now contains **Email & Google Setup**. For a local hackathon machine, the admin can enter SMTP and Google OAuth settings from the UI. Local secrets are stored in the git-ignored `instance/integrations.json`. On Render/production, environment variables still take precedence.

Email test failures now show the real SMTP error to the admin instead of only a generic failure message.

### Gmail defaults
- Host: `smtp.gmail.com`
- Port: `587`
- Security: `STARTTLS`
- Username/From: your Gmail address
- Password: Google App Password (not normal Gmail password)

Google Sign-In still requires real OAuth credentials from Google Cloud. CivicOS no longer exposes technical configuration instructions to citizens when OAuth is unavailable.
