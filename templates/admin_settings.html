Citizen Email OTPNo Google Cloud account is required. CivicOS sends a 6-digit verification code through the SMTP account configured above.
OTP policy: codes expire after 10 minutes, are stored as secure hashes, allow a maximum of 5 incorrect attempts, and resend is throttled for 60 seconds.
Hackathon continuity: on 127.0.0.1/localhost only, if SMTP delivery fails CivicOS can show the generated OTP on the verification page so the demo is not blocked. This fallback is disabled on normal deployed hosts. Real citizens still require working SMTP.
Citizen email lifecycle: account registration sends a 6-digit email OTP valid for 10 minutes. After a worker submits completion proof, no closure email is sent yet. Only after authority approval does CivicOS send the citizen a signed 14-day Verify Resolution & Rate Work link. If dissatisfied, the citizen can request reopening with fresh evidence.
Gmail requirement: Gmail normally requires 2-Step Verification + an App Password; your normal Gmail password will not work. For deployment, prefer Render environment variables so secrets do not live in the project filesystem. Local settings are stored in a git-ignored instance/integrations.json.
