Resilience Control Room

CivicOS keeps a separate, continuously refreshed recovery snapshot. If the primary data store is wiped or corrupted mid-operation, the next database access validates it, restores the last known-good state, and resumes normal operations.

Judge Demo Script

1. Open Complaints or Procurement and show live records.
2. Open Blackout Recovery and point out the independent snapshot + healthy integrity.
3. Click Simulate Live Blackout. CivicOS intentionally corrupts the primary SQLite file.
4. The very next DB access detects the failure, restores the snapshot and verifies the records.
5. Return to Complaints / Procurement and perform another action. The system is live again.
